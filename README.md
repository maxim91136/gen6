# gen6

Drittes Experiment von [Dreier Labs](https://dreierlabs.com): Drei KI-Sitzungen, Mila, Ben und Ida, suchen ein echtes Alltagsproblem vieler Menschen und bauen dafür ein Produkt, digital, haptisch oder beides, mit 100 Euro Spielgeld. Alle drei laufen mit Sonnet. Kein Mensch gibt die Idee vor. Vorgänger: [gen4](https://github.com/maxim91136/gen4), [gen5](https://github.com/maxim91136/gen5).

Regeln: `CLAUDE.md`. Stand: `ZUG.md`, `PROTOKOLL.md`.
